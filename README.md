## 🚀 Local Development

No package managers or build tools are required. You can preview and run the project immediately:

### Option 1: Direct Browser Launch
Double-click `index.html` or open it directly in Google Chrome, Edge, Firefox, or Safari.

### Option 2: Using VS Code Live Server
1. Open this repository folder in **VS Code**.
2. Install the **Live Server** extension (by Ritwick Dey).
3. Right-click `index.html` and select **"Open with Live Server"**.

### Option 3: Using Python HTTP Server
Run from the repository root:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000` in your web browser.

## 🌐 Deploying to GitHub Pages

This project is configured with relative asset paths and a root `index.html`, making it ready for instant deployment on GitHub Pages:

1. **Commit and Push Your Changes:**
   ```bash
   git add .
   git commit -m "Complete portfolio redesign for Angelo Varghese"
   git push origin main
   ```

2. **Enable GitHub Pages:**
   - Go to your repository on GitHub: `https://github.com/angelotech07-afk/PORTFOLIO`
   - Click on **Settings** > **Pages** (under the "Code and automation" sidebar).
   - Under **Build and deployment**:
     - **Source**: `Deploy from a branch`
     - **Branch**: Select `main` and folder `/ (root)`
     - Click **Save**.

3. **Visit Your Live Site:**
   Within 1–2 minutes, your website will be live at:
   `https://angelotech07-afk.github.io/PORTFOLIO/`

## 📄 Managing Your Resume PDF

The portfolio references `Angelo_Varghese_Resume.pdf` in both the hero and resume sections.

To update your resume:
1. Export your finalized resume from Word/Canva/LaTeX as a PDF.
2. Rename the file to `Angelo_Varghese_Resume.pdf`.
3. Place it in the root folder, overwriting the placeholder.
4. Commit and push the updated PDF:
   ```bash
   git add Angelo_Varghese_Resume.pdf
   git commit -m "Update official resume PDF"
   git push origin main
   ```
