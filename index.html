Primary Internship Project ExpenseAI — AI-Powered Personal Expense Analysis System

During my internship at Postulate Info Tech Private Limited, I worked on the architecture, data modeling, and machine learning components of ExpenseAI, an intelligent system designed to transform raw financial transaction data into structured, actionable spending intelligence.

Core Responsibilities & Technical Work:

  • Personal Expense Analysis: Designed and implemented automated data parsing pipelines to ingest, validate, and structure variable personal transaction records.
  • Data Processing & Preparation: Cleaned historical financial datasets with Pandas and NumPy, handling missing attributes, formatting discrepancies, and duplicate transaction entries.
  • Spending Pattern Analysis: Computed key summary statistics, temporal spending velocities, and category breakdowns to uncover user behavioral patterns.
  • Machine Learning-Based Categorization: Implemented classification models using Scikit-learn to automatically assign uncategorized spending entries into budget domains based on merchant descriptors and transaction text.
  • Anomaly Detection: Developed heuristic and statistical outlier detection models to identify irregular charges, duplicate payments, or spending surges exceeding typical thresholds.
  • Expense Forecasting: Engineered predictive trend analysis models to project month-end expense totals based on historical moving averages and spending trajectory.
